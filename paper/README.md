# The KYC-NLI paper

An ACL-format draft (long paper). Every number in it comes from a script, so it
can be regenerated end to end.

```
paper/
  main.tex           the paper -- prose and structure
  references.bib     two tiers: AUDITED and UNVERIFIED (read the header)
  figures/           GENERATED by scripts/make_figures.py  (PDF + PNG)
  tables/            GENERATED by scripts/make_tables.py   (LaTeX)
```

## Compiling it

There is no LaTeX on the development machine, and ACL papers are normally built
on Overleaf anyway:

1. On Overleaf, **New Project → Templates → search "ACL"** and open the official
   *ACL Rolling Review* template. It supplies `acl.sty` and `acl_natbib.bst`,
   which this draft needs and does not include.
2. Upload `main.tex` (replacing the template's), `references.bib`, and the
   `figures/` and `tables/` folders, keeping the folder names.
3. Set the compiler to **pdfLaTeX** and compile.

`main.tex` uses `\usepackage[review]{acl}`, which anonymises the PDF and adds
line numbers. Switch to `\usepackage{acl}` only for the camera-ready version.

## Regenerating everything

From the repository root, in this order -- each step reads what the one before
it wrote:

```bash
python scripts/noise_robustness.py      # ~15 min; every system at every noise level
kyc-nli risk-coverage --steps 50        # ~7 min; selective curves, dev-tuned thresholds
python scripts/make_figures.py          # paper/figures/
python scripts/make_tables.py           # paper/tables/
python scripts/check_paper.py           # structural check, no LaTeX needed
```

Never edit `figures/` or `tables/` by hand. Change the result, then regenerate.

## Before submitting -- the checklist

- [ ] **Verify the 17 UNVERIFIED references.** `check_paper.py` lists them. Each
      is a well-known paper, but none was checked against its primary record in
      this project, and the entries deliberately omit page numbers and uncertain
      co-authors. Confirm each on the ACL Anthology or publisher's page.
- [ ] **Decide on release.** The draft says "we introduce", not "we release".
      Whether the benchmark and code are published, and under what licence given
      Dakshina's CC BY-SA terms, is the project owner's decision (CLAUDE.md).
- [ ] **Compile and check the page count.** ACL long papers allow 8 pages of
      content; Limitations, Ethics and references do not count. The draft has
      four full-width figures and will likely run over. The first candidates to
      move to an appendix are Figure 2 (motivation) and Table 4 (languages).
- [ ] **Read the prose numbers against the tables.** Tables are generated;
      numbers quoted in sentences are copied by hand from the same results files.
      If any result was regenerated, search `main.tex` for the old value.
- [ ] Remove anything that de-anonymises the submission (repository URLs,
      acknowledgements) until camera-ready.

## What the evaluation got right that a reviewer will probe

These are the protocol choices most likely to be questioned, and where the
answer lives:

| Question | Answer |
| --- | --- |
| Is any test document in training? | No. Split by identity; asserted zero overlap. `tests/test_io.py` |
| Were the noise-level results on the same documents? | Yes -- identical 1,050 instances at every level, asserted in `scripts/noise_robustness.py` |
| How was the abstention threshold chosen? | On **dev**, then applied to test. Test-tuned ("oracle") points are used only for impossibility claims. `docs/m4-selective-prediction.md` |
| Why are the intervals wide enough to trust? | Bootstrap over contrast groups, not instances, and order-invariant. `tests/test_significance.py` |
| Is the noise model invented? | Measured from Tesseract. `docs/m1-ocr-calibration-findings.md` |
